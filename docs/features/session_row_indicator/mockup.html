来源级确认

父 P、自身失败；子 C 失败；兄弟 D 失败。查看 C 后，P 只扣掉 C 的贡献，仍保留 P 和 D 的提醒。查看 P 只确认 P，不能清除 D。孙来源同样一次从所有祖先减去。后续干净运行结束不能自动确认旧失败，权限回复非 2xx 不能清除 pending。

iOS 蓝色提醒另按行确认：打开蓝色父行 P，确认当时已知的 C/D 版本，子内容仍未读，祖父行不随之确认。孩子有新版本时 P 再提醒；黄红绿或状态未知时不顺带确认后代。

断线或超过确认有效期：停止绿色呼吸，不亮蓝；保留黄红并加“状态待同步”。请求未完成或失败不是 idle；只有同 host/project 的成功完整快照缺项才可确认不活跃。
