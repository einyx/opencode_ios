04 · After — Files & diff

Additions read as accent, not green

The changes surface joins the palette: accent-tinted additions, secondary removals. Deletions were never red in the shipped code — that part of the preview was aspirational.

Token migration

What actually changes in code

  • Everything flows through DesignTokens. Views reference Brand.primary, Neutral.surface… — changing the values re-skins the app with a ~4-file diff.
  • Manual cleanups: QuestionCardView has 7 hardcoded .blue sites (a latent second blue — becomes accent); SettingsStyle folds into the shared tokens.
  • Stays as-is: session triage lights (gold/red/green/blue per their own spec), gold = pending, sage = connected.
Contrast

One caveat to watch

  • Terracotta on ivory ≈ 3.3:1 — fine for icons, borders and ≥15pt semibold, tight for small body text.
  • Small accent text (kickers, counts) uses a darkened step #B4573A on light surfaces; dark mode lifts to #D2704C.
  • Accent never carries meaning alone — counts stay text, statuses keep icons/labels.
Docs & lint

The authority moves with it
