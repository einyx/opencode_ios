Chat UI — Claude interaction model, Liquid Glass materials

The Quiet Tech spec gave the chat screen a coherent visual language, but the interaction model never changed: a nav bar plus a second toolbar row, a stat block glued to the composer, half-width tool tiles, and a control column taller than the input. This round rebuilds the screen around the Claude app's model — minimal chrome, content scrolling under floating surfaces, one compact row per tool call — and dresses the floating surfaces in iOS 26 Liquid Glass.

Mockup only. Implementation notes at the bottom: the app targets iOS 17, so every glass surface needs a material fallback behind #available(iOS 26.0, *).

4 · Implementation notes

  • glassOne glass helper, one fallback. A GlassSurface view modifier: .glassEffect(.regular.interactive(), in: .rect(cornerRadius:)) on iOS 26+, .ultraThinMaterial + hairline stroke on iOS 17–25. Every floating surface goes through it, so the fallback never drifts.
  • glassThe composer floats above the tab bar, never under it. The iOS 26 tab bar is a floating pill that overlaps the content, so a bottom-anchored composer would sit underneath it. On iOS 26 the composer is the tab view's bottom accessory (tabViewBottomAccessory) — the system then stacks the two into one glass island. On iOS 17–25 the composer stays in the layout above the classic tab bar.
  • iconApp icon + greeting. The pixel-art robot is gone: the icon is the same eight-spoke asterisk in the brand blue on the ink background, and the empty chat greets you with that mark over “How can I help you?” — the Claude screen in the reference.
  • glassGroup adjacent glass. Wrap the header pill, the chip row and the composer in one GlassEffectContainer so they blend into a single island instead of three separate blurs.
  • layoutComposer floats. Move the composer out of the column into an overlay above the tab bar, and let the scroll view run underneath it. The message list needs bottom padding equal to the composer height.
  • layoutModel / branch chips replace the header chips. The model chip moves from the header into the chip row above the composer; the header keeps the session title and the context ring only.
  • layoutStat block leaves the composer. Token counts, cache hit and the usage quota move to the session sheet / Settings; the composer keeps only transient turn state, and that fades when idle.
  • layoutUser message becomes a bubble. Right-aligned, 84% max width, 20pt radius — Claude's treatment. This replaces the accent stripe from the Quiet Tech spec.
  • layoutOne row per tool call. The "N tool calls" group header and the file-card grid both go; every call renders the same compact row, expandable in place.
  • riskWhat I have not verified: the glass rendering itself (no iOS 26 simulator in the pinned set — it is on iOS 18.5), the composer's effect on scroll anchoring and keyboard avoidance, and whether the bubble treatment survives Dynamic Type at the largest sizes.
