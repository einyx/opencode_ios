4 · Detail: chat markdown does not follow the design system

The chat renders markdown through swift-markdown-ui with no theme applied, so the library default applies: no colour on code blocks, links in plain text colour, and H1/H2 at 2em/1.5em — 32pt and 24pt inside a 16pt body, which breaks the 22/16/13/12 type scale the whole app is built on. Proposed: one theme, tokens only.

5 · Out of scope for this pass

  • laterApp icon. The current icon is a pixel-art robot, unrelated to the Quiet Tech palette. A flat electric-blue mark would make the icon match the app for the first time.
  • laterToken leaks. A handful of views still use raw Color.blue / .secondary instead of DesignColors. Mechanical cleanup, no visual change.
  • laterDynamic Type. Several fixed .system(size:) fonts do not scale with the user’s text size.
